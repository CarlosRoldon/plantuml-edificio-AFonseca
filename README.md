# Edificio PlantUML - RPG Manager

Repositorio individual con la resolución de los 21 retos del juego educativo **Edificio PlantUML**, aplicando los conceptos al sistema de software **RPG Manager**.

## Estructura del Proyecto
* `lobby/`: Retos introductorios y conceptos iniciales de modelado.
* `piso1/`: Casos de uso, relaciones include/extend, diagramas de actividades y carriles (swimlanes).
* `piso2/`: Clases, visibilidad de atributos, relaciones estructurales (composición/agregación), objetos y paquetes.
* `piso3/`: Diagramas de secuencia, retornos, fragmentos combinados (loop, alt), estados y estados compuestos.
* `piso4/`: Arquitectura de software con diagramas de componentes, nodos de despliegue, entidad-relación y contenedores C4.
* `azotea/`: Reto integrador de interacción dinámica para el motor de combate.
* `JuegoAcabado.png`: Evidencia de finalización completa del juego.
